BIRTHDAY SURPRISE - SETUP STEPS

1. Extract this folder to D:\ALl_PAYMENT_INTG\Wish
2. Open VS Code > File > Open Folder > D:\ALl_PAYMENT_INTG\Wish
3. Open index.html.
4. Right-click index.html > Open with Live Server.
   (Install the Live Server extension if needed.)

PERSONALISE:
Open script.js and change:
const birthdayName = "Beautiful Human";
Use the birthday person's name.

PROJECT FILES:
index.html - page structure and the three stages
style.css - pastel design, 3D-style cake, floating effects and transitions
script.js - envelope opening, letter transition, photo previews, confetti
assets/pink-3d-envelope.png - generated 3D envelope illustration

STEPS WHEN VIEWING:
1. Tap the envelope or "tap anywhere".
2. The envelope zooms away and the letter appears.
3. Press "Continue to your birthday".
4. Make a wish; tap photo frames to add your own pictures.

The photos are only previewed locally in the browser; they are not uploaded.
Internet is used for Google Fonts. The rest runs locally.
